FeelGood Conduite

Politique de confidentialité

Dernière mise à jour : 10 septembre 2026. Éditeur : Thomas Mallard — th.mallard75@gmail.com

Qui est responsable

FeelGood Conduite est une application d’accompagnement à la conduite. Le responsable du traitement est Thomas Mallard. Les données sont hébergées dans l’Union européenne (Francfort).

Données collectées

  • Compte : adresse e-mail, prénom, mot de passe chiffré.
  • Trajets : trace GPS, horodatage, scores et événements de conduite calculés sur le serveur.
  • Lien parent : e-mail du parent ou tuteur, scores globaux partagés (jamais la carte ni les adresses).

Nous ne vendons pas ces données. Nous n’affichons pas de publicité.

Pourquoi

Le GPS sert uniquement à calculer tes indicateurs de conduite (sérénité, scores). Un parent invité, avec le code que tu lui transmets, ne voit que ces scores globaux.

Durée et suppression

Les données sont conservées tant que le compte existe. Dans l’application : Profil → Supprimer mon compte. Tu peux aussi écrire à th.mallard75@gmail.com.

Tes droits

Tu peux accéder à tes données, les rectifier ou les effacer. Pour une réclamation : Commission nationale de l’informatique et des libertés (CNIL).

Cette page est publique, sans compte, pour l’App Store et pour tes utilisateurs.
